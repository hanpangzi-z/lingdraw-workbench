# PPT 功能迁移验收清单

本清单是“投标 PPT”迁入灵绘后的交付契约。每项必须同时满足：入口可达、行为与源实现一致、自动化测试通过；仅页面能够打开不计为完成。

## 基线

- 源业务源码：238 个手写 TypeScript/TSX/CSS/Prisma/SQL 文件，约 23,841 行。
- 源自动化测试：15 个测试文件、119 个 `it(...)` 用例。
- 固定保留：5 套模板、6 套主题、6 种自适应商品布局。
- 不迁移：源用户、项目记录、PostgreSQL 数据以及 `storage/` 历史文件。

## 最终门禁

1. 源 119 个测试、PPT 新增集成测试、灵绘既有回归测试全部通过或有明确的迁移前既存失败记录。
2. Windows 与 Docker 两种启动方式均完成数据库迁移、种子、健康检查和优雅停止。
3. 使用 Excel、PDF、Word、旧 PPT 各完成一次真实端到端导入并导出可在 PowerPoint 中编辑的 `.pptx`。
4. 亮色、暗色及窄屏截图完成视觉复核，PPT 页面中不再出现 FOLIO 品牌外壳。
5. 上表全部更新为“通过”后，才可宣称全量迁移完成。
