# LingDraw Workbench

**把想法、参考素材和 AI 创作放进同一个工作台。**

LingDraw（灵绘）是一款面向设计师、内容创作者和团队的 AI 视觉创作工作台。围绕无限画布组织需求与素材，通过对话进行创意探索，再衔接图片生成、编辑、绘画标注和素材管理，减少在多个工具之间搬运内容的步骤。

适用于电商主图、详情页、社交媒体海报和品牌视觉探索。复杂需求可先确认方案，再按模块生成并逐项修改；按自己的环境选择模型服务，或接入 ComfyUI 工作流。

## 主要功能

| 功能 | 用途 |
| --- | --- |
| 无限画布 | 在画布上组织提示词、图片与工作流节点，支持分组以及工作流导入导出。 |
| 设计智能体 | 根据需求与参考素材选择处理方式，支持方案确认、多模块生成和局部修改。 |
| 创意生图 | 通过对话描述需求，上传参考附件，选择模型、比例与生成数量。 |
| 绘画与图像工具 | 提供绘画标注、角度控制和图像增强等创作入口。 |
| 素材管理 | 集中整理和复用素材，配套浏览器采集与 Photoshop 连接工具。 |
| 多种模型接入 | 支持 OpenAI 兼容、Gemini、方舟、ModelScope、RunningHub 等接入方式，以及 ComfyUI。 |
| 任务与结果管理 | 关联请求、任务状态与生成成果，支持结果查询和恢复。 |
| 账号与管理 | 提供注册审核、角色权限、积分记录与使用统计。 |
| PPT 工作台 | 集成演示文稿创作、编辑与导出。 |

## 创作流程

1. 新建项目，上传参考素材并描述需求。
2. 选择直接生成、图片编辑，或先确认复杂任务的模块方案。
3. 生成内容并在工作台比较、编辑，有问题时修改对应部分。
4. 整理素材和成果，保存项目或导出用于交付。

## 快速开始

Windows 安装并启动 Docker Desktop，准备 Python 3.11 或更新版本及 Node.js 环境。复制配置模板，填写数据库密码和内部服务令牌：

```powershell
Copy-Item design-agent.env.example design-agent.env
.\setup-agent-env.bat
.\start-windows.bat
```

首次访问 `/admin/setup` 创建管理员，普通账号注册后由管理员审核。在 API 设置中配置模型服务，或连接自己的 ComfyUI。

停止服务：

```powershell
.\stop-windows.bat
```

Docker、数据存储及反向代理配置见 [部署说明](DEPLOYMENT_SOURCE.md)。

## 项目结构

- `main.py`、`agent_service/`：应用接口与任务编排。
- `design-agent-ui/`：设计智能体界面。
- `drawing-ui/`、`login-ui/`：绘图与登录界面。
- `ppt-app/`：演示文稿工作台。
- `static/`：页面及构建资源。
- `tools/`：浏览器采集与 Photoshop 连接工具。
- `tests/`：应用与请求恢复测试。
