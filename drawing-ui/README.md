# 绘画标注

灵绘内置的绘画和图片标注工具，入口位于“角度控制”下方。主界面记住上次选择的工具，由主服务以同域 iframe 加载 `/static/drawing-app/index.html`。

支持自由绘画、矩形、菱形、椭圆、箭头、直线、中文文字、图片拖放/粘贴、选择/移动/缩放/旋转、橡皮擦、撤销重做和缩放平移。顶部可导出 PNG；菜单还可打开/保存源文件和导出 SVG。右上角及菜单中的“重置画布”会先弹出确认框，默认聚焦“取消”；取消、Esc 或默认回车均保留画板，只有点击“确认清空”才会彻底删除当前账号的本地画板记录，并重新初始化编辑器，清空图形、嵌入图片、图形库、名称和撤销/重做历史，恢复白色背景、默认位置和 100% 缩放。此操作无法撤销；导入或导出进行中暂不可重置。已有保存任务完成后才删除记录，避免旧数据回写；清理失败显示重试入口。

“创意生图”中每张生成图片右下角的画笔按钮可将图片发送至绘画标注。工作台等待画板就绪后传递图片，导入后自动选中并适配视野；已有内容保留，新图片放在右侧。导入使用现有的同域媒体路由，将图片嵌入画板并随画板保存，支持撤销。消息检查来源窗口和站点，请求按顺序处理并去重。

顶部“导入创意生图”先预览用途、图片与可编辑说明。标注改图分别发送未经重绘的原始图片文件与画布 PNG 示意图；画布中的文字自动填入修改说明，纯圈线不推测意图，必须补充要求。多张图片时可选择修改对象。草图生图则使用完整画布作为构图参考。

下载和回传使用同一个高清渲染器，直接读取内嵌原始图片并重新绘制矢量元素。可选“跟随原图”“2K（长边 2048）”“4K（长边 4096）”，保持完整画布比例，包含裁剪、旋转、标注和 32 个画布单位的边距。带图片默认跟随有效原始像素密度，多图取最大密度，整张画布长边最多 4096；纯绘画默认 2K。旧画板按实际内嵌文件尺寸计算，不需要迁移；以前已被压缩的文件无法自动恢复丢失细节。

导出对话框显示 PNG 实际宽高，放大低清图片时提示无法恢复原始细节。画布预览最高 1024 像素，原图预览最高 512 像素；切换清晰度复用预览，仅在下载或回传时生成最终 PNG。编码错误保留画板和修改说明，不自动降低清晰度。取消、关闭和重置释放临时预览与下载链接；渲染结束或失败都会清空临时 canvas 的像素缓冲。

创意生图回传消息可选携带 `canvasSize`、`generationSize`，旧消息仍可使用。标注改图按所选原图比例确定目标尺寸，草图生图按完整画布比例确定，生成宽高向上对齐到 16 的倍数。输入框显示并选中独立的“画布尺寸 · 宽×高”；此选择只针对当前附件，不写入全局默认尺寸。用户可手动切换内置尺寸。请求使用 `size` 和默认关闭的 `size_is_explicit`，明确选择后不再受提示词尺寸解析影响，失败重试和重新生成保留该尺寸。

绘画来源的 `source`（有配对组）、`annotation`、`sketch` 附件在后端转换时保留文件字节，不经过固定 1536 像素缩放或 JPEG 重编码。原生图片插入也保留文件，避免组件默认的 1440 像素缩放。高清请求不自动降尺寸或重复提交收费任务；模型尺寸/文件限制仍由接口反馈，报错后可在保留的草稿中调整。模型原生接口若只接受比例和分辨率档位，沿用该协议的映射，最终成品像素取决于模型支持范围。

附件经 `/api/ai/upload` 保存，工作台桥接保留 `source` / `annotation` 角色及 `annotation_group` 配对信息。创意生图显示“原图”“标注说明”标签，删除任意一张会移除整组；一次请求支持一组标注改图，保留原有输入文字和普通附件。附件容量检查按整组执行，不自动发起生成。后端所有生图入口统一补充图片用途规则，按原图、标注图顺序发送，跳过商品参考图覆盖规则；不支持双图输入的 RunningHub 工作流会提示切换模型。模型仍可能误解标注，当前版本不提供蒙版级区域约束。

画板（包括嵌入图片、视图位置、名称和图形库）使用 IndexedDB 按当前登录用户名保存。保存失败会提示导出备份，不会显示保存成功。浏览器数据清除后本地画板会丢失；跨浏览器或设备使用时需要导出/导入源文件。绘图本身不调用 AI 服务，也不会扣除积分。

开发与构建：

```sh
cd drawing-ui
npm ci
npm test
npm run build
```

验收不调用收费模型：`npm test` 检查尺寸、原图传递和画板存储；项目根目录运行 `.venv-agent/bin/python -m unittest tests.test_drawing_hd tests.test_annotation_edit` 检查供应商转换与拒绝后的行为。`npm run dev -- --host 127.0.0.1 --port 37626` 后访问 `/static/drawing-app/hd-qa.html` 可运行真实浏览器 PNG 渲染检查（横竖 4K、细字、纯绘画、多图裁剪旋转、画布外标注、旧数据、取消与编码失败）。`tests/browser_drawing_hd_server.py --port 37625` 提供完整工作台的隔离模拟接口，并在 `/__qa/status` 记录上传文件尺寸、哈希和生成请求参数。

构建结果及字体输出至 `static/drawing-app/`，纳入发布文件后无需额外 Node 服务，直接沿用 Python 主服务的登录保护。深色模式和中英文切换跟随灵绘主界面。

绘图组件使用 MIT 许可的 [Excalidraw](https://github.com/excalidraw/excalidraw)。字体从已安装包复制到同域目录，使用该包内各字体的许可证；正常绘画不依赖公共 CDN。集成方式参考 [官方文档](https://docs.excalidraw.com/docs/@excalidraw/excalidraw/integration)。
